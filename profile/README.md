# Not Bad Company

A software studio in Hilversum, the Netherlands. KvK 42185336.

**[Krentenweger](https://krentenweger.nl)** is our own product: the weekly offers of thirteen Dutch supermarket chains in one list you can search, filter and follow. Rust scrapers, an Astro site, and a Flutter app for iOS and Android. Deciding which category and brand a product has, and whether two chains sell the same product, is moving to Claude, with a person checking what it is unsure about.

**[Ledgerbee](https://github.com/Not-Bad-Company/ledgerbee)** is bookkeeping for freelancers that stays free: receipts read on the phone, invoices and quotes with a scan-to-pay code, bank import, and tax figures ready when they're due, starting with the Netherlands. A Rust server with SQLite and a Flutter app, source on GitHub.

For clients we build websites, web applications and internal tools, from scratch.
